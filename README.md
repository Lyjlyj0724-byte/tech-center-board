# 技术中心设备看板

本地部署、局域网内多人共享编辑的设备生产看板系统。

## 功能

| 模块 | 说明 |
| --- | --- |
| 总览 | KPI（型号数 / 今日产量 / 本月出货）、机器类型分布、中越柬出货分布示意图（点击国家弹出该地区设备清单，设备与照片一一对应，含地区出货汇总）、最近出货 |
| 设备 | 设备/辅具台账（编号 / 名称 / 类别 / 类型 / 型号 / 国家 / 厂区 / 今日产量 / 视频），新增、编辑、删除，按类别 / 国家 / 类型 / 关键词筛选 |
| 详情页 | 每台设备/辅具一个介绍页：基本信息、可编辑图文介绍、照片墙（上传/删除/看大图）、视频区、出货分布与记录、日产值 |
| 视频 | 每台设备可上传视频（单个最大 1GB，mp4 / webm / mov 等），在线播放、删除，带上传进度条 |
| 产量 | 按日期录入每台设备的日产量；同一天重复保存自动覆盖 |
| 出货 | 登记出货（日期 / 产品线：设备·辅具·龙头 / 关联设备 / 数量 / 发往 / 备注），支持编辑、删除，按产品线 / 目的地 / 关键词筛选查询 |
| 报表 | 自定义周期生成 A4 纸质报表：总产量、良品、**综合良率（收益率）**、出货量、设备明细、出货明细、签批栏，一键打印或另存 PDF |

数据存储在项目目录 `data/db.json`，视频与照片存储在 `uploads/`，全部保存在本机。

## PPT 数据

系统已导入《技术中心设备研发2026年（1-7）月.pptx》的数据：20 种设备（出货 432 台）、16 种辅助工具（出货 1980 个）、龙头月度出货（1190 个），以及 PPT 中的 26 张设备/辅具照片。设备照片已挂在对应设备详情页；视频可后续在设备列表逐台上传。

重新导入（会先清除旧 PPT 导入数据）：

```bash
node server/import-ppt.js
```

## 一、首次安装（只需要做一次）

```bash
npm install
```

## 二、日常使用（开发模式）

```bash
npm run dev
```

- 本机打开 <http://localhost:3000>
- 后端数据服务在 8100 端口，前端自动代理

## 三、局域网共享部署（推荐给多人使用）

在一台常开的电脑（作为服务器）上：

```bash
npm run build     # 生成前端产物 dist/（只需在代码更新后执行）
npm run server    # 启动服务，监听 0.0.0.0:8100
```

局域网内其他电脑访问：

```
http://<服务器IP>:8100
```

**查看服务器 IP**：在服务器上运行 `ipconfig`，取「IPv4 地址」（如 `192.168.1.50`），则访问地址为 `http://192.168.1.50:8100`。

**如其他电脑打不开**：在服务器上放行防火墙端口 —— 控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 TCP 8100 → 允许连接。

**协作方式**：所有终端读写同一份数据，页面每 8 秒自动同步他人改动，无需手动刷新。技术人员在「设备」页手动录入设备信息、上传视频；在「产量」页按天录入产量。

**开机自启（可选）**：用 `pm2`、`nssm` 或任务计划程序把 `npm run server` 注册为开机启动。

## 四、数据备份

定期复制整个项目目录下的 `data/` 与 `uploads/` 两个文件夹即可完成全量备份。

## 技术栈

- 前端：React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui
- 后端：Node.js + Express + JSON 文件存储（无外部数据库依赖）
- 视频：multer 上传，本地磁盘存储，HTML5 播放
